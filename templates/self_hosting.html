Free self-hosted software

Run KwaCart on your own computer or server.

All facilitation tools, live sessions, the Academy and archives are available without a subscription. You control the instance and its data.

Run locally

  1. Install Python once. Use Python 3.13 from python.org (3.12 and 3.14 also work). On Windows, select “Add python.exe to PATH” if offered.
  2. Download and extract the ZIP. Windows: right-click → Extract All. Mac: double-click the ZIP. Open the extracted folder containing manage.py and the Start KwaCart files. Do not run inside the ZIP.
  3. Start the launcher. Windows: double-click Start KwaCart.bat. Mac: open Start KwaCart.command. Linux: run sh "./Start KwaCart.command" in that folder. The first launch installs packages and needs internet.
  4. Create your first login. Follow the email and password prompts. Password characters are invisible while you type. This is your local account, not a GitHub or Replit login.
  5. Use the browser. Once “KwaCart is ready” appears, your browser should open. Click Login and use your new account. If it does not open, paste http://127.0.0.1:8000/ into the browser’s address bar.

Keep the launcher window open. Press Ctrl+C in it to stop KwaCart. Next time, start the same launcher from the same folder; your account and saved work remain there.

Read the complete Windows, Mac and Linux walkthrough, including troubleshooting.

No Stripe, Cloudinary or Replit account is needed. This remains a browser-based application that requires Python, not a standalone desktop installer.

The local address is only for this computer: sending it to someone else will not let them join. Live participants on other devices need a shared instance. Do not expose the local development server to the internet.

Run a shared server

Use config.settings.selfhost with a private secret key, your allowed domain names, persistent storage and a production web server. Put HTTPS and media delivery behind a reverse proxy. The included self-hosting guide covers these settings.

SQLite is suitable for a small instance; use your own PostgreSQL server when you need more simultaneous writers. Software use requires no subscription, but hardware, electricity, domains or optional hosting services can have their own costs.

Keep your data safe

Back up both the database and media folder, keep private keys outside the repository, and install security updates. The operator decides who can register, how the instance is exposed and which retention settings to apply.

Self-hosting does not remove an operator’s responsibilities for participants’ information. Set appropriate policies and notices for your own use, particularly when sessions involve children or sensitive material.
